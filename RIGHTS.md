# Rechte und Veröffentlichung

Für die Initialisierung wird keine pauschale Open-Source- oder Datenlizenz gewählt. Öffentlich sichtbar bedeutet keine allgemeine Weiterverwendungslizenz.
Dossiertexte, Zitate, Daten und fremder Code dürfen erst nach Prüfung ihrer jeweiligen Rechte übernommen werden. Originaldossiers sind derzeit nicht enthalten.
Eine spätere Lizenzentscheidung dokumentiert getrennt Code, Dokumentation, Daten und fremde Quellen.
